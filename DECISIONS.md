# Решения по проекту

## 2026-11-15 — PostgreSQL запускаем в Docker
- **Выбрали:** сервис `db` (образ `postgres:17`) в `docker-compose.yml`, данные хранятся в томе `pgdata`.
- **Альтернативы:** поставить PostgreSQL прямо на Windows; облачная БД.
- **Почему:** одна команда `docker compose up -d` поднимает одинаковую базу у всех и в CI. Windows не засоряется, путь с символом ` не мешает. Позже в этот же файл добавим Redis, Celery и бота.

## 2026-11-15 — Пароли и настройки храним в `.env`
- **Выбрали:** настройки лежат в `.env`, его нет в git (он в `.gitignore`). В git коммитим шаблон `.env.example`.
- **Альтернативы:** записать значения прямо в `docker-compose.yml` или в код.
- **Почему:** секреты не попадают в репозиторий, а на сервере можно подставить другие значения, не меняя код.
